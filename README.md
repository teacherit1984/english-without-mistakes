Английский без ошибок

Этот бот — умный помощник для изучения английского языка. Он работает на платформе MAX и создан для работы с учебниками Spotlight, а также с любыми другими PDF-учебниками, которые вы загружаете сами.

Что умеет бот

Бот позволяет загружать PDF-файлы учебников через админ-панель и сохраняет их в своей базе. Пользователь может выбрать нужный класс, а затем отправить номер страницы. Бот прочитает эту страницу из учебника. Если текст в PDF представлен в виде картинки, бот автоматически использует Tesseract OCR, чтобы распознать его.

После получения текста нейросеть YandexGPT формирует ответ. Она составляет список ключевых слов с переводом, объясняет суть текста простым и понятным языком, а также придумывает задания для закрепления материала.

Кроме работы с учебником, бот может объяснить любую тему по английскому языку, даже если её нет в книге. Достаточно просто написать тему, например Present Simple. Бот помнит контекст диалога, поэтому можно задавать уточняющие вопросы.

Для учеников реализована квиз-игра. Бот может сгенерировать вопросы по одной или нескольким страницам учебника. В конце ученик видит свой результат, а все достижения сохраняются в личном профиле и доступны по кнопке «Мой прогресс».

Для администраторов предусмотрена удобная панель. Через неё можно добавлять новые учебники, просматривать статистику, список пользователей и топ самых активных учеников.

Технологии

Проект написан на языке Python версии 3.11 и выше. Для взаимодействия с платформой MAX используется библиотека maxapi. Ответы генерирует нейросеть YandexGPT через API Yandex Cloud. Для работы с PDF-файлами применяется библиотека PyMuPDF. Распознавание текста с картинок выполняет Tesseract OCR с языковыми пакетами rus и eng. Все сетевые запросы выполняются асинхронно с помощью asyncio и aiohttp.

Структура проекта

Основной файл bot.py содержит всю логику работы бота: обработку сообщений, меню, скачивание файлов, запросы к нейросети и логику квиза. В папке books хранятся загруженные PDF-учебники и файл registry.json, который служит реестром классов. Файл users.json хранит данные о пользователях и их результатах. Файл requirements.txt содержит список необходимых зависимостей Python. Файл .env предназначен для хранения секретных ключей.

Как запустить

Сначала необходимо установить Python 3.11 или выше, а также Tesseract OCR с языковыми пакетами для русского и английского языков. Затем установите все зависимости командой pip install -r requirements.txt.

Создайте файл .env и добавьте в него три переменные: MAX_BOT_TOKEN с токеном вашего бота, YANDEX_API_KEY с ключом от Yandex Cloud и FOLDER_ID с идентификатором вашей папки.

После этого запустите бота командой python3 bot.py.

Безопасность

Файл .env содержит секретные ключи и токены. Убедитесь, что он добавлен в файл .gitignore и никогда не попадает в открытый репозиторий на GitHub.
