# Английский без ошибок

## Описание
«Английский без ошибок» — это мини-приложение (Web App) для информационно-коммуникационной образовательной платформы Сферум. Сервис использует искусственный интеллект (YandexGPT) для объяснения сложных тем из школьных учебников английского языка простым и понятным языком для учеников 5–11 классов.

**Ключевые возможности:**
- **Работа с PDF-учебниками:** Приложение умеет находить нужный материал по номеру страницы.
- **Система OCR (Optical Character Recognition):** Встроена поддержка распознавания текста со сканированных страниц и изображений с помощью движка Tesseract. Это позволяет «читать» даже старые или фото-учебники.
- **Структурированный урок:** ИИ не просто пересказывает текст, а выделяет лексику, объясняет грамматику и дает подсказки к упражнениям.

## Технологический стек
- **Python 3.12** — основной язык разработки
- **FastAPI** — высокопроизводительный веб-фреймворк
- **Uvicorn** — ASGI-сервер
- **YandexGPT API** — генерация интеллектуальных ответов
- **PyMuPDF (fitz)** — работа с PDF-документами и конвертация страниц в изображения
- **Tesseract OCR + Pytesseract** — распознавание текста на изображениях (сканах)
- **Pillow** — обработка изображений для OCR
- **Docker** — контейнеризация для удобного развертывания

## Структура проекта
- `main.py` — основной код приложения (бэкенд, логика OCR, интеграция с ИИ и фронтенд)
- `books/` — папка для хранения PDF-файлов учебников (необходимо создать вручную)
- `Dockerfile` — инструкция для сборки Docker-образа
- `requirements.txt` — зависимости проекта с фиксированными версиями
- `README.md` — документация по запуску

## Как запустить локально (без Docker)

### 1. Подготовка
Убедитесь, что у вас установлен [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki).
В коде (`main.py`) необходимо указать правильный путь к исполняемому файлу `tesseract.exe` (по умолчанию настроено на `D:\Tesseract-OCR\tesseract.exe`).
