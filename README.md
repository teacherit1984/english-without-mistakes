# Английский без ошибок

## Описание
«Английский без ошибок» — это мини-приложение (Web App) для информационно-коммуникационной образовательной платформы Сферум. Сервис использует искусственный интеллект (YandexGPT) для объяснения сложных тем из школьных учебников английского языка простым и понятным языком для учеников 5–11 классов.

## Технологический стек
- Python 3.12
- FastAPI (веб-фреймворк)
- Uvicorn (ASGI-сервер)
- YandexGPT API (генерация ответов)
- Docker (контейнеризация)

## Структура проекта
- `main.py` — основной код приложения (бэкенд и фронтенд-разметка)
- `Dockerfile` — инструкция для сборки Docker-образа
- `requirements.txt` — зависимости проекта с фиксированными версиями
- `README.md` — документация по запуску
