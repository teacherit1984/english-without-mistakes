Английский без ошибок

Это чат-бот для платформы Сферум, который помогает ученикам с английским языком по учебникам Spotlight. Бот работает на базе искусственного интеллекта и умеет искать информацию прямо в тексте учебника 10 класса. Также он распознает текст со сканированных страниц или фото заданий, если обычный текст из PDF не считывается.

Как это работает

Когда ученик задает вопрос, бот сначала ищет похожий материал во всем учебнике, а не только на одной странице. Если страница является картинкой, включается система OCR, которая превращает изображение в текст. После этого нейросеть формирует ответ простым языком, без сложных терминов. Весь бот написан на Python и работает асинхронно, поэтому он не зависает, даже если несколько человек пишут ему одновременно.

Что использовалось при разработке

Код написан на Python 3.12. Для связи с платформой МАХ используется библиотека maxapi. Ответы генерирует YandexGPT. Чтобы бот мог искать по тексту учебника, подключена векторная база FAISS и модель SentenceTransformers. Текст из PDF извлекается через PyMuPDF, а картинки распознаются с помощью Tesseract OCR. Все запросы к API обрабатываются асинхронно через aiohttp, чтобы бот работал быстро.

Структура файлов

В файле bot.py находится основная логика бота и меню с кнопками классов. В engine.py реализовано ядро системы: там происходит чтение PDF, запуск OCR и отправка запросов к нейросети. Файл rag.py отвечает за поиск по базе знаний, а indexer.py создает эту базу из PDF-учебника. Папка books хранит сами учебники, а vector_db — созданную базу данных. Файл .env содержит секретные ключи, его нельзя выкладывать в открытый доступ.

Как запустить проект

Сначала нужно установить Python 3.12 и Tesseract OCR. В файле engine.py обязательно проверить путь к tesseract.exe, он должен совпадать с тем, куда установлена программа на компьютере. Затем установить все нужные библиотеки командой pip install -r requirements.txt. Создать файл .env и прописать туда токен бота, ключ Яндекса и ID папки. Перед первым запуском выполнить python indexer.py, чтобы создать базу знаний из учебника. После этого можно запускать бота командой python bot.py.

Важно про безопасность

Файл .env с паролями и ключами добавлен в список игнорируемых файлов, поэтому он не попадет на GitHub. Если кто-то захочет скачать проект, ему нужно будет просто создать свой .env и вставить туда свои данные.
